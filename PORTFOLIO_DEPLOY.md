# Portfolio GitHub Pages deployment

The portfolio is published from the `portfolio-pages` branch at its root (`/index.html`). It is a standalone static HTML/CSS/JavaScript site with no build step.

## Enable hosting

1. Open **https://github.com/vikasraghuwanshi85/AI-Automation/settings/pages** while signed in to GitHub.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **portfolio-pages** and **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish publishing. The expected website address is **https://vikasraghuwanshi85.github.io/AI-Automation/**.
5. Visit the site on desktop and mobile, and verify each project link and the email button.

## Editing

Edit `index.html` in the `portfolio-pages` branch and commit changes. GitHub Pages will redeploy automatically after the branch is selected in Pages settings.

For a top-level URL like **https://vikasraghuwanshi85.github.io/** instead, create a dedicated public repository named `vikasraghuwanshi85.github.io` and move the portfolio files there; the existing AI Automation project stays unaffected.

## Notes

- Contact uses a `mailto:` link and does not store messages.
- Images use the public GitHub avatar URL only.
- No private repository sources, credentials, or client code are embedded.
- Portfolio content is based on publicly accessible repositories and a professional CV; check descriptions and figures before sharing broadly.
